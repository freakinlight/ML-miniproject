Under the hood

Why this is classification

The target is species, which can only be Adelie, Chinstrap, or Gentoo. Because the model predicts one of several labels—not a continuous number—this is a multiclass classification problem.

Data provenance

Real observations, honest limitations.

The data were collected near Palmer Station, Antarctica. This educational model only recognizes three species present in that dataset and should not be used for biological field identification outside its scope.
